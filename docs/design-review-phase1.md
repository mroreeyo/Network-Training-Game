# 1단계 시안 비교 기록

작성일: 2026-11-10
대상: 챕터 1 스테이지 1 화면과 결과 화면 (실제 화면)을 `design/mockups/stage-packet.html`, `result-return.html`, `result-pass.html`과 나란히 비교했습니다. PC는 1280px, 휴대폰은 360×740px입니다.

월드맵은 PR 5에서 시안과 같은 구조(컨베이어 한 줄, 위아래로 번갈아 붙인 표지판, 휴대폰 세로 흐름)로 만든 것을 확인했습니다.

## 시안과 달라서 고친 것

| 차이 | 조치 |
| --- | --- |
| 경로 표의 장비 칸이 화면 폭을 똑같이 나눠 가져서 벨트(구간)가 짧았음 | 장비 칸은 내용만큼, 구간이 남는 폭을 채우게 함 |
| 패킷 상자 제목이 가운데 정렬이었음 | 왼쪽 정렬로 고침 (정렬 규칙: 상자와 도장만 가운데) |
| 휴대폰 첫 화면에 경로 표만 보이고 패킷 상자가 화면 아래에 있었음 | 휴대폰에서는 패킷 상자를 경로 표보다 먼저 보여 줌 |
| 휴대폰에서 포커스가 간 버튼이 아래 고정 트레이 밑으로 스크롤됨 | 스크롤할 때 아래쪽에 트레이 높이만큼 여유를 둠 |

## 시안과 다르지만 그대로 둔 것

| 차이 | 이유 |
| --- | --- |
| 작업 지시서 오른쪽에서 "반송 N번"이 힌트 버튼 위에 있음 (시안은 옆) | 힌트를 펼치면 힌트 카드가 같은 칸에 쌓여서, 옆으로 두면 칸이 넓어짐 |
| 휴대폰에서 작업 지시서를 제목 한 줄로 접음 | 검수 기록 결정 A의 추천안 |
| 패킷 상자 위에 이번 작업을 알려 주는 문장이 있음 (시안에 없음) | 작업이 여러 번인 스테이지에서 지금 할 일을 알려 줌 |
| "마지막 라벨 떼기" 버튼이 있음 (시안에 없음) | 보내기 전에 붙인 순서를 고칠 수 있게 함 |
| 휴대폰 첫 화면에서 놓을 자리의 아래 20px이 트레이에 가려짐 | 보이는 부분(약 90px)을 누를 수 있음. 카드가 4장 이상이면 다시 확인 |

## 검수 체크리스트

| 항목 | 결과 |
| --- | --- |
| 가장 먼저 눈에 들어오는 것이 게임판이다 | PC 통과. 휴대폰은 패킷 상자와 놓을 자리가 첫 화면에 보임 |
| 금지 목록에 해당하는 요소가 없다 | 통과 (토큰 검사가 그라데이션, 그림자, 흐림 효과를 막음) |
| 토큰 파일에 없는 색, 간격, 글꼴 값이 없다 | 통과 (`npm run check:tokens`). 예외는 0단계 검수 기록 3절과 같음 |
| 접근성: 드래그 없이 플레이, 키보드 | 통과. 누르고 놓기와 키보드로 스테이지 1을 끝까지 깸 |
| 접근성: 모달 포커스, Esc | 통과 |
| 휴대폰 360px에서 가로 스크롤 없이 끝까지 플레이 | 통과. 스테이지 1을 터치로 끝까지 깸 |
| 게임 이름을 가려도 다른 학습 앱과 구별된다 | 직접 보고 판단해 주세요 |

실제 Pretendard 글꼴은 개발 환경에서 CDN에 접속할 수 없어 확인하지 못했습니다. 대체 글꼴로 비교했습니다.

## 스테이지 2~4를 넣으면서 찾아 고친 것 (PR 10)

| 문제 | 조치 |
| --- | --- |
| PC에서 라우터가 2대인 스테이지 4의 경로 표가 작업대보다 넓어 화면이 옆으로 넘침 | 라우터 칸이 줄어들면 두 포트가 위아래로 쌓이게 하고, 경로 표가 세로로 바뀌는 폭을 1040px에서 1200px로 올림 |
| 휴대폰에서 트레이 카드의 MAC 주소가 길면 화면이 10px 넘침 | 카드와 트레이 칸이 글자 때문에 늘어나지 않게 하고, 긴 주소는 다음 줄로 내려가게 함 |

1440, 1280, 1210, 1200, 1100, 900, 360px에서 스테이지 1, 2, 4의 가로 넘침과 칸 밖으로 나간 글자가 없는 것을 확인했습니다.
